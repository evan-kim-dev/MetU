# 데모 합성 에셋 안내

레포에 **실제 영수증 이미지나 개인 문자를 커밋하지 마세요.**  
시연용 합성 이미지는 로컬·시연 기기에서만 만들고 업로드합니다.

## 합성 영수증 (저녁 식사 · 품목 채움)

품목 예시(상호·카드번호·개인정보 금지):

- 식사 1
- 맥주 2잔
- 사이드 1

안내용:

1. 임의 상호(예: `Demo Bistro`)·임의 금액만 넣은 이미지 생성
2. 호스트 폰에서 밍글링 데모 지출에 영수증으로 업로드
3. 품목이 파싱되면 게스트 "저는 술 안 마셨어요" 경로 확인
4. 품목이 없으면 대본 v2 ③을 **칩 전체 제외(exclude)** 로 대체 (`docs/demo-checklist.md`)

## 합성 택시 영수증 (게스트 제안 · 선택)

K14 병합 후에만 사용합니다. K14가 없으면 대본 v2 ⑤(선택 장면)을 건너뛰어요.

- 상호·개인 식별 정보 없이 "택시 / 합승" 정도의 합성 이미지
- 게스트가 "내가 냈어요"로 제안 → 호스트 승인함에서 승인
