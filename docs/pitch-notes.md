# 피치 보조 노트 (MetU)

심사·발표용 메모예요. 코드가 아니라 말할 거리 정리이고, 공개 소개 화면 `/about` 과 같은 내용을 따라가요.
**숫자(사용자 수, 절감액, 정확도, 매출, 시장 규모)는 쓰지 않아요.** 확인 안 된 주장은 "미검증"으로 적었어요.

## 한 줄

여행 중 카드 알림이 오면 입력 없이 장부가 쌓이고, 환율이 적용되고, 동행자와 정산까지 이어져요.

## 어떻게 동작하나요

1. 카드 알림 내용을 MetU 수집 주소(`/api/ingest/*`)로 전달해요. iOS 는 단축어 자동화가 필요해요.
2. 서버가 알림을 읽어 장부 후보를 만들어요. 조건을 모두 통과하면 자동 저장, 아니면 확인 대기로 남아요.
3. 해외 결제는 실시간 환율(`lib/fx`)로 원화를 서버가 계산해요. 환율을 못 가져오면 임의 값을 쓰지 않아요.
4. 동행자 잔액을 `lib/ledger/settle.ts` 로 계산하고, 송금은 앱을 여는 딥링크로 안내해요.

"3초" 같은 시간은 측정한 날의 값을 구두로만 말해요. 측정 방법은 [demo-checklist.md](./demo-checklist.md) 를 따라요.

| 아이디어 | 상태 | 전제 |

| 정산 송금 연계 | 아이디어 | 송금 서비스 제휴 필요. 지금은 딥링크만 |

## 개인정보

- 알림 본문은 AI 호출 전에 `redactSms` 로 마스킹해요.
- 카드 전체 번호는 저장하지 않아요.
- 자동 저장은 기본 한도 300,000원 이하일 때만 해요(서버 설정 `AGENT_AUTO_MAX_KRW` 로 바꿀 수 있어요). 자동 저장은 되돌릴 수 있어요.
- 취소·환불·삭제성 알림은 항상 확인 대기예요.

## 데모 시나리오 60초 대본

준비 절차는 [demo-checklist.md](./demo-checklist.md) 를 따라요. 아래는 말할 순서예요(시간은 대략의 배분이에요).

1. (0~10초) "여행 중엔 결제할 때마다 장부를 적기 번거로워요. MetU는 카드 알림만 오면 알아서 적어요."
2. (10~25초) 데모 모드에서 시뮬 알림을 보내요. 수신함/가계부에 지출이 생기는 것을 보여줘요. 걸린 시간은 그날 측정한 값이 있을 때만 말해요.
3. (25~40초) 지출 상세에서 외화 금액과 적용된 환율, 원화 금액을 보여줘요. "환율은 서버가 가져와 계산해요."
4. (40~52초) 정산 화면에서 동행자별 주고받을 금액과 공유/송금 앱 링크를 보여줘요. "송금은 앱 안에서 하지 않고 안내만 해요."
5. (52~60초) "한도 이하만 자동 저장하고 되돌릴 수 있어요. 수익 모델은 아직 아이디어 단계예요."

## 예상 질문과 답변

**왜 PWA 인가요?**
설치 없이 링크로 열고 홈 화면에 추가할 수 있어서, 심사·팀원 공유가 빨라요. 네이티브 앱은 이후 과제예요. 앱 스토어 심사나 출시 일정에 대한 계획은 확정된 게 없어요(미검증).

**iOS 한계는요?**
웹앱 단독으로는 다른 앱의 알림을 읽을 수 없어요. 그래서 iOS 는 단축어 자동화로 알림 내용을 보내는 방식이고, 사용자가 한 번 설정해야 해요([ios-shortcut-build.md](./ios-shortcut-build.md)). 완전 자동은 아니에요.

**수익은 어떻게 내나요?**
아직 매출은 없고 모델은 검증 전이에요. 후보는 카드 수수료 비교 제휴, 정산 송금 연계, 팀 플랜, 항공·호텔 제휴 링크예요. 호텔 Agoda 링크만 연결돼 있고 실제 수익은 확인하지 못했어요. 앞의 세 가지는 제휴나 기능 개발이 먼저 필요해요.

**개인정보는요?**
알림 본문은 AI 호출 전에 마스킹하고, 카드 전체 번호는 저장하지 않아요. 자동 저장은 한도 이하만 하고 되돌릴 수 있어요. 마스킹이 모든 경우를 완벽히 막는다고는 말할 수 없어요(미검증, 테스트 케이스 범위 안에서만 확인).

**AI 가 금액이나 환율을 계산하나요?**
아니요. 금액·환율·분담은 서버의 순수 함수가 계산해요. AI 는 알림 문구를 해석하는 데만 써요.

**정확도는 얼마나 되나요?**
측정한 정확도 수치가 없어요(미검증). 확신이 낮은 건 자동 저장하지 않고 확인 대기로 남겨요.
